# Resource MegaPack
The Modernization Megapack lives on! Along with legacy content from the community unistore such as the modern/beta and alpha textures as optional addons via resource, skin and behaviour packs!

# Requirements
- A physical/digital copy of Minecraft: New Nintendo 3DS Edition
- Update 1.10 (otherwise known as numc3ds) installed on your console
- The <b>LATEST</b> version of Luma
- access to the console's SD card via ftp or SD card reader

## Installation
1. Download and extract the latest release or source code.zip onto your PC.
2. Run the 1.10 (also known as numc3d) update/mod at least once before installation; this will create the necessesary directories and folders.
3. Move the extracted folder named <b>Minecraft 3DS</b> into the root of your console's SD card
4. Once the files and folders have been moved you can access the content via their respective menus in-game
